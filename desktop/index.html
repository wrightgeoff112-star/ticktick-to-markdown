一份可以带走的笔记库

ZIP 解压后，每条任务或笔记对应一个 Markdown 文档，按清单整理。官方 CSV 不包含图片和附件；本工具会另外下载附件并提供本地链接。

可在 Obsidian 中打开解压后的文件夹，也可使用其他支持 Markdown 的工具阅读。不同工具对任务状态、提醒等字段的支持可能不同。

优先保留官方 CSV；生成备份受限时，从任务接口导出，并附原始 JSON 和来源说明。附件通过未公开接口获取，失败项会列在结果和 manifest.json 中。同一次应用会话内重试可复用已下载附件，关闭应用后不支持断点续传。
